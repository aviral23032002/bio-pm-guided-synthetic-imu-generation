Problem statement

Core problem

Human Activity Recognition (HAR) from IMU sensors suffers from a fundamental data scarcity problem. Collecting and labeling high-quality 6-axis IMU sequences is expensive, intrusive, and time-consuming — particularly for rare or clinically relevant activities (falls, rehabilitation exercises, gait disorders). This leads to severely imbalanced class distributions and poor generalization across subjects and deployment environments.

Research gap

Existing data augmentation for IMU relies on hand-crafted signal transforms (jitter, rotation, time-warping) that lack semantic control. Recent deep generative models for time series (TimeGAN, SSSD) are trained from scratch on raw signals and cannot condition generation on both activity semantics and subject-style simultaneously. No prior work uses a pretrained biosignal foundation model as the representation scaffold for a conditional generator.

Proposed solution — CAR-IMU

We propose the Class-conditional Autoregressive IMU model (CAR-IMU). Rather than generating raw IMU waveforms, we operate entirely in the structured representation space of Bio-PM — a pretrained biosignal encoder. A lightweight transformer decoder learns to autoregressively predict the next Bio-PM token embedding conditioned on (1) an activity-class prefix token and (2) an optional subject-style embedding. Synthetic token sequences can be used directly for representation-space augmentation, or optionally decoded back to approximate raw IMU via a lightweight signal decoder.

Novel angle Low compute Practical impact

Formal problem setup

Let X ∈ R^(T×6) be a 10-second IMU window (T timesteps, 6 axes). Bio-PM encoder E: X → Z ∈ R^(N×D) maps it to N token embeddings of dimension D. Let c ∈ C be an activity class label and s be a subject-style embedding. We train an autoregressive model p_θ(z_t | z_<t, c, s) and sample synthetic token sequences Ẑ = {ẑ_1, ..., ẑ_N}. Downstream HAR classifiers are then trained on real tokens ∪ synthetic tokens.

Proposed pipeline — full system

Bio-PM encoder is frozen throughout. Only the autoregressive decoder and optional signal decoder are trained.

Model architecture — CAR-IMU decoder

Input: sequence of token embeddings with positional encoding, prepended with a learned class-embedding token [CLS_c] and subject-style token [SUBJ_s] (mean-pooled from K=5 reference windows of that subject).

Architecture: 4-layer causal transformer decoder. D_model = D (same as Bio-PM token dimension, typically 256–512). 4 attention heads. FFN dim = 2×D. Causal mask enforces autoregressive generation. Output projection: D_model → D (linear, no activation). Trained with MSE loss on the next token embedding.

Parameter count: ~2–6M params depending on D — trainable on a single GPU in under 2 hours, or on CPU overnight with WISDM-scale data.

Prior work — positioning CAR-IMU

Your contribution sits at the intersection of three threads. Cite all three and position CAR-IMU as their synthesis.

Thread 1 — time-series generation

TimeGAN (Yoon et al., NeurIPS 2019) — joint adversarial + supervised training of an embedding network. Limitation: trains embedding and generator together, no domain-pretrained encoder, GAN instability. CAR-IMU improvement: uses a frozen, domain-pretrained Bio-PM encoder — the representation space is far more structured before generation training even begins.

SSSD-S4 (Alcaraz & Strodthoff, 2022) — diffusion model for time-series imputation using S4 backbone. Limitation: imputation, not generation; no class conditioning for HAR. CAR-IMU improvement: explicit class prefix conditioning, autoregressive generation, smaller model.

TSGM (Nikitin et al., 2023) — general benchmark framework for TS synthetic data. Limitation: generic statistical representations, no biosignal-specific inductive biases. CAR-IMU improvement: Bio-PM encoder provides domain-aligned, activity-discriminative representations as the generation substrate.

Thread 2 — self-supervised learning on IMU

LIMU-BERT (Xu et al., IPSN 2021) — BERT-style masked pretraining on raw IMU for downstream HAR. Most related: similar encoder design to Bio-PM. CAR-IMU improvement: we go beyond classification and use the learned space for conditional generation, a capability LIMU-BERT does not address.

CPC / TNC on IMU (Oord et al.; Tonekaboni et al.) — contrastive SSL for temporal segments. CAR-IMU improvement: we use the contrastive representation space as a generative prior — a direction neither paper explores.

Bio-PM (your anchor work) — pretrained biosignal encoder producing token-level representations. CAR-IMU treats this as a frozen semantic oracle and places a trainable generator on top. Explicitly frame this as "generation in the Bio-PM latent space."

Thread 3 — HAR augmentation

Um et al. (2017) — seminal survey of hand-crafted IMU transforms: jitter, scaling, rotation, permutation. Limitation: no learned semantics, no class-targeted control. CAR-IMU improvement: class-conditional generation produces semantically coherent synthetic samples, not arbitrary transforms.

SensGen / ActSynth — GAN-based IMU generation for HAR augmentation. Limitation: GAN training instability, no explicit class conditioning through a prefix mechanism, no compatibility with pretrained encoders. CAR-IMU improvement: stable autoregressive training, explicit class prefix, synthetic tokens are by construction in Bio-PM representation space.

SMOTE variants for HAR — interpolation in feature space for minority class augmentation. Limitation: linear interpolation, no temporal structure, operates on handcrafted features. CAR-IMU improvement: learned generation captures temporal dynamics and activity-specific motion patterns.

Your positioning sentence

"CAR-IMU is the first method to place a class-conditional autoregressive generator in the token representation space of a pretrained biosignal foundation model, enabling semantically controlled IMU synthesis without adversarial training or raw-signal generation."

Day 5 · build CAR-IMU model skeleton

Model code (person A, others can review)
Implement CausalTransformerDecoder class
4 layers, causal attention mask, positional encoding (sinusoidal or learned), output head D_model→D. ~100 lines of PyTorch.
Implement prefix token mechanism
Learnable class embedding table C ∈ R^(|C|×D) and subject projection W_s ∈ R^(D×D). Prepend [CLS_c] and [SUBJ_s] to each token sequence before feeding to decoder.
Implement training loop + MSE loss
Teacher forcing: input z_{1..N-1}, target z_{2..N}. MSE loss on all positions. AdamW optimizer, lr=1e-4. Gradient clipping at 1.0. Log loss every 100 steps.
Implement autoregressive sampling
Given prefix [CLS_c][SUBJ_s], sample z_1, z_2, ..., z_N one token at a time. Add Gaussian noise with temperature τ to each predicted embedding before feeding as next input. Implement both greedy (τ=0) and stochastic (τ>0) decoding.

Dataset — WISDM (primary recommendation)

Why WISDM

WISDM (Wireless Sensor Data Mining) is the best fit for a 2-week project: small enough to preprocess in hours, large enough for meaningful results, well-labeled, widely cited (easy to compare against prior work), and freely available. It has a known class imbalance problem (walking dominates), making it a natural testbed for class-balanced augmentation.

Known class imbalance (motivates augmentation)

Walking: ~38% · Jogging: ~30% · Standing: ~10% · Sitting: ~9% · Upstairs: ~7% · Downstairs: ~6%. The last three classes are the natural targets for synthetic augmentation — exactly the use case CAR-IMU addresses.

Preprocessing steps

  • Segment each subject's continuous recording into 10s windows (200 samples) with 50% overlap → ~5,000–8,000 windows total
  • Normalize each axis to zero mean, unit variance per subject (subject-normalized) or globally (global-normalized). Use subject-normalized for subject-style experiments.
  • Train/val/test split: 70/15/15 by subject (leave-N-subjects-out, not random windows). Never mix windows from the same subject across splits.
  • Run Bio-PM encoder on all windows, save token store. This only needs to happen once.

Backup datasets (if WISDM results are weak)

UCI-HAR 30 subjects, 6 activities, 50Hz — largest public benchmark, most baselines. More axe channels (accel + gyro). Harder to preprocess.

PAMAP2 9 subjects, 18 activities, IMU + heart rate. Richest, but small N makes few-shot scenarios more interesting.

Downstream tasks & metrics

Two categories: realism (is synthetic data believable?) and utility (does it actually help?). Report both.

Realism metrics

Bio-PM FID primary

Fréchet distance between real and synthetic token distributions in Bio-PM space. Use Bio-PM encoder as the feature extractor (analogous to Inception FID for images). Compute per class and aggregate. Target: synthetic FID ≤ 1.5× the real-vs-held-out FID baseline.

MMD (RBF kernel)

Maximum mean discrepancy between real and synthetic token distributions. More interpretable than FID at small N. Use permutation test for significance. Target: p > 0.05 (synthetic and real not distinguishable by MMD test).

Precision & recall

Kynkäänniemi et al. (2019): Precision = fraction of synthetic samples inside real manifold; Recall = fraction of real manifold covered by synthetic. Both high = good. Low precision = synthetic off-distribution. Low recall = mode collapse.

UMAP coverage

Visual: do synthetic samples visually overlap real clusters per class? Quantify with k-NN density ratio. Target: ≥ 90% of real clusters have synthetic neighbors within 2× the median real intra-class distance.

TSTR accuracy

Train-on-Synthetic, Test-on-Real. Train HAR classifier on synthetic only, evaluate on real test set. Measures how informative synthetic data is. Target: TSTR accuracy within 5pp of real-trained accuracy.

Utility (downstream) metrics

Macro F1 delta (Δ-F1) primary

HAR macro F1 with real+synthetic training vs real-only baseline. Report for syn_ratio ∈ {0.1, 0.25, 0.5}. Target: Δ-F1 ≥ +1.5pp at 25% synthetic ratio. Minority classes should show larger gains (+3–5pp).

Low-data recovery curve

F1 vs fraction of real data used (10%, 25%, 50%, 100%). For each fraction, compare real-only vs real+synthetic. Steeper recovery = synthetic is more useful. Report as a line plot — one of the key paper figures.

Minority-class F1 recovery

Downsample one activity (e.g., downstairs) to 10% of original. Measure minority F1 before and after augmentation with CAR-IMU. Target: ≥ 80% recovery of full-data minority F1.

vs hand-crafted aug (ablation)

Compare CAR-IMU augmentation to jitter + rotation augmentation (Um et al. baseline) at the same augmentation ratio. Shows that learned generation outperforms signal-space transforms.

vs unconditional model (ablation)

Compare class-conditional CAR-IMU to an unconditional version (no prefix). Shows that class conditioning is critical — random generation without activity control hurts classification.

Classifier choices for downstream evaluation

Run all utility experiments with 3 classifiers on Bio-PM token representations: (1) linear probe (most interpretable), (2) 2-layer MLP (small capacity), (3) 1D-CNN on the token sequence (captures temporal order). Report all three — if gains hold across classifiers, the result is robust.

Future extensions

These are directions you can mention in the paper's conclusion section to demonstrate awareness of the space. The best 1–2 could become follow-up papers.
1

Latent diffusion upgrade (DDPM / DDIM in token space)

Replace the autoregressive decoder with a denoising diffusion model trained on the token-sequence matrix. DDPM in Bio-PM space benefits from better-conditioned latents than raw signal. Use classifier-free guidance for activity conditioning. Directly extends CAR-IMU and is the natural next paper.

Novelty 4/5Medium GPU required
2

Cross-subject style transfer via flow matching

Condition generation on a "source subject" embedding to produce synthetic data in the style of rare or unseen subjects. Use conditional flow matching (Lipman et al., 2022) to learn straight-line ODE paths between classes. Directly addresses clinical HAR where rare populations (elderly, patients) are underrepresented.

Novelty 5/5Strong clinical motivation
3

Lightweight signal decoder: tokens → raw IMU waveforms

Train a 1D-CNN decoder that maps generated token sequences back to approximate raw IMU waveforms, enabling traditional signal-level augmentation pipelines to use CAR-IMU outputs. Supervised by reconstruction loss on real (IMU, token) pairs. Opens CAR-IMU to models that don't use Bio-PM embeddings.

3–4 days extra workHigh practical value
4

Few-shot HAR via synthetic data bootstrapping

Given only 5–10 real examples of a new activity (e.g., fall detection), use CAR-IMU to generate a full training set for that activity. This reframes the project as a few-shot learning enabler rather than just an augmentation tool — a stronger and more publishable narrative.

Strong paper angleSmall experiment, high impact
5

Multi-modal conditioning: activity + context (location, time of day)

Extend the prefix mechanism to include environmental context tokens (indoor/outdoor, morning/afternoon, device position). Enables richer conditional generation where activity and context jointly determine the motion pattern — relevant for realistic simulation of wearable device deployments.

Long-term directionNew dataset needed
6

Privacy-preserving synthetic HAR data release

Use CAR-IMU to release a synthetic version of a private clinical IMU dataset that preserves statistical properties without exposing individual subjects' motion signatures. Evaluate with differential privacy guarantees and membership inference attack resistance. New application area with clear societal value.
